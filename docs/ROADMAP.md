# نقشهٔ مراحل پروژه

|---|---|---|
| P0 — اتصال و پایه | شاخهٔ Go در GitHub، محیط مستقل سرور، Project Brain، ثبت نسخه و CI | build/test موفق و تطبیق دقیق نسخهٔ سرور با GitHub |
| P1 — بررسی سازگاری | بررسی Parserها، ساخت تنظیمات، DTOها، کتابخانهٔ Android و هستهٔ دقیق؛ نمونه‌های سالم/خراب | ماتریس پروتکل/Transport/قالب با شواهد و محدودیت‌های روشن |

## معیارهای مشترک

- هر مرحله checkpoint، تست و commit قابل‌پیگیری دارد.
- کارهای مستقل موازی‌اند؛ نوشتن نسل یک منبع و انتشار، ترتیبی و تراکنشی است.
- مقادیر حداقل/حداکثر و واحد بازه برای هر لینک جداست؛ زمان بعدی در دیتابیس ذخیره می‌شود.
- «پینگ» به معنی تأیید ترافیک از کانفیگ است؛ پینگ TCP معیار نهایی نیست.
- شکست عامل تست، قطع اینترنت سرور و شکست خود کانفیگ تفکیک می‌شوند.
- هیچ کانفیگی تأیید دائمی نمی‌گیرد؛ محتوای قدیمی، قرنطینه و لاگ پاک‌سازی محدود دارند.
- یادگیری فقط رتبه‌بندی قواعد اثبات‌شده را خودکار می‌کند؛ ساخت قاعدهٔ جدید تابع آزمون و جلوگیری از regression است.
- موفقیت در Linux Xray، واردکردن و اتصال Android یا کارکرد روی اپراتور ایران را ثابت نمی‌کند.

P2 مدیریت منابع و پنل آزموده و مستقر شده است. دکمهٔ «دریافت اکنون» همراه Worker در P3 اضافه می‌شود؛ فعلاً هیچ کنترل دریافت نمایشی وجود ندارد.
