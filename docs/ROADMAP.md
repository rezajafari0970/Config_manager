# مسیر فعلی پروژه

درخواست ۲۰۲۶-۱۰-۳۰ مسیر قبلیِ بانک آزمایش و یادگیری را جایگزین کرد.

| بخش | وضعیت / معیار |
|---|---|
| دریافت مستقل لینک‌ها | فعال؛ زمان‌بندی، تایم‌اوت، جایگزینی اتمی و حذف تکراری |
| قالب مشترک JSON | P7؛ حفظ اطلاعات اتصال و تنظیمات انتقال در پوستهٔ @shenvpn |
| Output ساده | فهرست کانفیگ و یک خروجی JSONL، هر کانفیگ یک خط |
| حذف بانک | مهاجرت schema6؛ بدون نمونهٔ دائمی، تاریخچه یا دادهٔ یادگیری |
| بررسی هسته و اتصال | هستهٔ ثابت، محیط ایزوله و شواهد جدا؛ صف قابل بازیابی |
| Android واقعی | هنوز انجام نشده؛ نیازمند APK/دستگاه و گزارش واقعی |
| نصب‌کنندهٔ خودکار | مرحلهٔ انتشار مستقل؛ نصب/ارتقا/بازیابی روی محیط تمیز باید آزموده شود |

JSONL قالب خروجی خواسته‌شده است. ساب Custom JSON نسخهٔ فعلی v2rayNG آرایه/یک شیء می‌خواهد؛ این دو قالب نباید با هم اشتباه شوند. تمام خطاهای سرور یا ناسازگاری پروتکل با تغییر فایل قابل اصلاح نیستند.
