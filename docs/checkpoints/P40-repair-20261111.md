# P40 — conservative shared input repair

Parent: 15a8b7d; worktree work/p40-parser-repair-20261111.
User asks to repair recoverable rejected inputs throughout all outputs, compare
all collected inputs across cores, bound network sampling to a few variants per
family, and report actual core failures separately from parser/network failures.

The pipeline uses probe v6 / share-compat v2, normal v8, Smart v12 / Ads v5.
Schema24 refreshes persisted version predicates and fences stale claims before
serving. Egress's existing version reconciliation includes convert.Version and
therefore requalifies its evidence without deleting its records or settings.
No legacy Residential code, source admission policy or deletion policy is restored.

Narrow repairs:
- Separate the VMess URI fragment before Base64 decoding. Preserve '+' during
  percent decoding; retain standard/raw and URL-safe decoding. Never fabricate
  payload bytes after corruption/truncation.
- Recognize the explicit VMess security/scy cipher alias with conflict checks.
  Never mistake it for TLS or downgrade an explicit cipher.
- Remove only exact empty-string snib/ech/pqv placeholders. Active extensions
  remain unresolved. WS type annotations are not applied as TCP headers.
- Normalize decimal port spelling (whitespace, Persian/Arabic digits). Missing,
  fractional, out-of-range or ambiguous ports are never guessed.
- Treat a bounded numeric realityVersion as source metadata only under REALITY.
  Missing REALITY keys and a truncated bare ty remain explicit input failures.
- Unwrap only complete validated IPv6 literals in protocol endpoint address
  fields. Do not modify HTTP Host, SNI, credentials or raw source bytes.
  The shared legacy VLESS fixed redirect then preserves this real endpoint.

The new endpoint repair is used by raw preparation and shared composition.
Immutable raw storage is unchanged. Candidate rules, version and exact SHA256
remain separate. Existing final-byte core + real connectivity publication gates
are mandatory; passing another version or another member grants no health.

Audit: scripts/repair-audit.py reads a private immutable snapshot, deduplicates
final candidates and builds each on official checksum-pinned Xray26.11.9,
26.10.31,26.7.28,26.5.9. Real HTTPS/DNS/UDP/QUIC/HTTP3 probes are restricted to
two representatives per family and the first two cores, plus composed Smart
profiles. A short-lived optional resume reuses only exact candidate hashes with
the identical core pins. Audit output does not grant production publication.
Private raw snapshots/results stay in .local; never commit credentials or
subscription URLs. All current sources plus previous failure examples are covered.
