# P2 — authenticated Persian source management

Date: 2026-10-29 (Asia/Tehran). Parent checkpoint: P0 foundation. Product target remains V2RayNG 2.3.6 / Lib v40 / Xray 26.7.28.

## Delivered

- Server-rendered Persian RTL panel, responsive at 1440 and 390 pixels.
- Administrator bootstrap, Argon2id login, durable sessions, logout and password change with global session revocation.
- Source create/edit/delete, confirmation page, pause/resume, min/max/unit validation, persisted random deadline and optimistic revision checks.
- SQLite migration v1, WAL/FULL durability, AES-GCM URL storage, URL deduplication through keyed hashes, redacted list display.
- Bounded authentication work, persisted rate limits, request/body deadlines, strict Origin and CSRF, secure cookies and response headers.
- Independent systemd service and TLS proxy deployment templates. The host deployment uses its existing managed certificate read-only and a separate listener. Existing enabled nginx site contents were hash-checked unchanged.

## Verification actually performed

Unit/integration tests cover invalid/private URLs, unsafe intervals, source secret absence in DB bytes, reopen persistence, wrong encryption key rejection, duplicate links, concurrent revision writes, stale updates/deletes, no resurrection after deletion, authentication, expired/revoked sessions, password changes, rate limiting, CSRF, Origin, escaping, redaction, body bounds and CRUD HTTP handlers.

Screenshots were visually reviewed. A browser-discovered Origin regression with Referrer-Policy no-referrer was fixed to same-origin and rerun successfully.

Deployment acceptance passed: dedicated low-privilege systemd service active/enabled, loopback listener, TLS 1.3 public address with browser certificate verification enabled, successful real login/logout, secure session cookie, and externally hidden health route. Production source count is zero; only synthetic tests were used.

## Limits and next step

No source fetch, config probe, Android execution or subscription export is enabled. P1's full compatibility matrix and P6 Android acceptance remain unfinished. A healthy panel does not establish healthy proxies. Run-now belongs to P3's real durable worker; no inactive run-now control is shown.

Next: bounded fetch drivers with deadlines, DNS/redirect/dial egress validation, conditional HTTP retrieval, durable revisions/jobs and atomic generation membership. Implement safe empty/error fallback only with independently refreshed real health. Do not execute arbitrary imported Custom configs before the planned core sandbox.
