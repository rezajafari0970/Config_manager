# P40 — ترمیم مشترک و مقایسه هسته‌ها

اصلاحات در schema24، normalv8، Smartv12 و Adsv5 فعال شد. تمام ۳۳ منبع حفظ شدند.
P39 egress، source admission، retention، کنترل حذف و چرخش خروجی حفظ شده‌اند.

- ۷۴۲ ورودی: ۷۳۲ فعلی + ۱۰ تاریخی/ارسالی؛ ۱۲ ورودی قبلاً متوقف‌شده قابل ساخت شدند.
- ۷۲۱ ورودی پس از ترمیم روی 26.11.9، 26.10.31 و26.7.28 پذیرفته شدند.
- ۲۱ ورودی پیش از هسته متوقف: ۱۹ کلید REALITY غایب، یک پورت خالی، یک لینک ناقص &ty.
- صفر ورودی با ردشدگی نهایی هسته هدف؛ این ادعای اتصال همه سرورها نیست.
- ۶۹۱ نامزد یکتا: ۱۰ نسخه اولیه VMess+TCP+TLS به‌علت allowInsecure رد شدند؛ strict TLS جایگزین پذیرفته شد و هنوز نیازمند اثبات اتصال مستقل است.
- 26.5.9 برای ۹ ورودی finalmask/fragment قدیمی‌تر ناسازگار است؛ هسته‌های جدیدتر آن‌ها را می‌پذیرند.
- ۳۲ نماینده تکی و ۱۷ Smart با هم‌زمانی۲ آزمایش واقعی شدند؛ نتایج کامل، جزئی، شکست و اجرا‌نشده جدا هستند.

ترمیم‌های محدود و نسخه‌دار شامل fragment/percent-encoding VMess، alias معتبر cipher،
placeholder دقیقاً خالی، ارقام و فاصله پورت، metadata مشخص REALITY و براکت IPv6 است.
پورت، کلید، TLS و ویژگی واقعی سرور حدس زده نمی‌شود. raw تغییر نمی‌کند.
تغییر نسخه مدرک قدیمی را باطل می‌کند و بازآزمایی همه خروجی‌ها را فعال می‌کند.
درایور VLESS plaintext همچنان NO ADDED ENCRYPTION است.

تست کامل race/vet/build، بازآزمایی تغییرات نهایی، مهاجرت DB واقعی و پنل mobile/desktop
موفق بود. خروجی دقیق تکی عادی و Smart سرویس فعال، روی دو هسته قبول و در Linux
HTTPS/DoH/DNS TCP وUDP/QUIC VN/HTTP3 موفق داشت.
Splash/Ads ابتدا پاسخ503 دادند؛ پس از بازآزمایی مستقل هرکدام دو خروجی آماده شدند و نمونه واقعی هر دو مسیر نیز تست کامل را گذراند. این اثبات، طبقه‌بندی مستقل Residential نیست.

v2rayNG2.3.6 و2.3.15 در توابع مرتبط Import/Custom Config بررسی شدند؛ بدنه‌های مرتبط یکسان
بودند. ۸۸ ترکیب speed/TUN روی سه هسته، شامل ۴ نامزد اصلی ردشده، بررسی شدند؛ هر چهار
جایگزین strict نیز موفق بود. اجرای واقعی APK و شبکه‌های ایران not_run است.
IPv6-only به‌دلیل محدودیت netns این آزمایش pending است، نه خراب.

نتایج عددی و pins در P40-validation.json است. گزارش خصوصی کاربر شامل متن خام موارد
ناقص، JSON اصلاح‌شده، نام‌ها و جدول تک‌تک ورودی‌هاست؛ در git قرار نمی‌گیرد.
