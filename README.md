# Config Manager — Go

دریافت مستقل کانفیگ از لینک‌ها، تبدیل خودکار به قالب مشترک JSON با نام `@shenvpn` و پنل فارسی **Input / Output / Setting**.

- Input: افزودن گروهی، ویرایش، حذف، توقف و دریافت فوری لینک‌ها؛ زمان‌بندی تصادفی ثانیه/دقیقه و تایم‌اوت مستقل.
- Output: فقط فهرست کانفیگ‌ها، نتیجهٔ تبدیل/هسته/اتصال، نمایش و کپی JSON و یک لینک خروجی **JSONL**؛ هر کانفیگ یک خط، بدون آرایه یا متن اضافه.
- Setting: نگهداری، دریافت موازی، تایم‌اوت و تنظیمات تبدیل/بررسی خودکار.
- قالب مشترک شامل DNS، SOCKS محلی، مسیریابی، آمار و سیاست نمونهٔ کاربر است. آدرس، احراز هویت، پروتکل و انتقال از خود کانفیگ می‌آیند. وابستگی‌های قابل تشخیص مسیر حفظ می‌شوند.
- اصل داده بدون تغییر و رمزگذاری‌شده باقی می‌ماند. حذف تکراری‌ها، جایگزینی اتمی خروجی هر لینک و عمر ثابت پیش‌فرض دو ساعت حفظ شده‌اند.
- **بانک آزمایش و تعمیر حذف شده است.** نمونهٔ دائمی، تاریخچهٔ نسخه‌ها، مدل‌های یادگیری و ساب‌های قدیمی وجود ندارند. تبدیل فقط تا زمانی باقی می‌ماند که منبع فعلی/زمان نگهداری اجازه دهد.

پروتکل‌های قابل تبدیل: VLESS، VMess، Trojan، Shadowsocks، WireGuard، Hysteria 2/Hy2، SOCKS5 و JSON/Custom JSON قابل تشخیص. Hysteria 1 در هستهٔ هدف پشتیبانی نمی‌شود؛ تبدیل اسم پروتکل آن را سازگار نمی‌کند.

هدف ثابت: **V2RayNG 2.3.6 / Lib40 / Xray 26.7.28**. هر خروجی باید از بررسی همین هسته عبور کند. پذیرش هسته به معنی اتصال نیست؛ اتصال HTTPS جدا بررسی و نمایش داده می‌شود. تغییرات فرضی مانند افزودن TLS تنها با اتصال تازهٔ موفق قابل انتشار هستند. سرور خاموش، اطلاعات ورود نادرست و قابلیت پشتیبانی‌نشده با تغییر JSON تضمین‌شده اصلاح نمی‌شوند.

**تفاوت قالب خروجی:** JSONL دقیقاً مطابق درخواست کاربر است. ساب Custom JSON در v2rayNG 2.3.6 آرایه یا یک شیء می‌خواند و واردکردن گروهی JSONL به‌عنوان ساب تأیید نشده/پشتیبانی‌شده نیست. هر JSON جداگانه قابل کپی برای ایمپورت است؛ آزمون Android واقعی هنوز انجام نشده است.

## توسعه

شاخهٔ `go/v2rayng-2.3.6`؛ `main` قدیمی مستقل می‌ماند. Linux، Go و Python 3 لازم‌اند. آزمون رابط به Chrome/Playwright نیاز دارد.

```sh
bash scripts/check.sh
XRAY_TEST_BINARY=/absolute/path/to/pinned/xray go test -v ./internal/convert
PLAYWRIGHT_MODULE=/path/to/playwright-core CHROME_PATH=/path/to/chrome python3 scripts/panel-browser-test.py
sudo -E python3 scripts/conversion-worker-test.py --live-canary 16
```

کارگر privileged فقط محیط ایزولهٔ هسته را مدیریت می‌کند؛ کانفیگ‌ها با UID غیرریشه، محدودیت منابع، فایل‌سیستم محدود و کنترل خروجی شبکه اجرا می‌شوند. دو سرویس systemd پس از بوت و خطای فرایند خودکار اجرا می‌شوند؛ هنگام خاموشی خود سرور پردازشی ممکن نیست.
