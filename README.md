# Config Manager — Go

دریافت مستقل کانفیگ از لینک‌ها، تبدیل خودکار به قالب مشترک JSON با نام `@shenvpn` و پنل فارسی **Input / Output / Setting**.

- Input: افزودن گروهی، ویرایش، حذف، توقف و دریافت فوری لینک‌ها؛ زمان‌بندی تصادفی ثانیه/دقیقه و تایم‌اوت مستقل.
- Output: فقط فهرست کانفیگ‌ها، نتیجهٔ تبدیل/هسته/اتصال، نمایش و کپی JSON و لینک اشتراک **آرایهٔ JSON** قابل Import؛ خروجی قدیمی JSONL نیز برای ابزارها حفظ شده است.
- Smart: خروجی ترکیبی با قالب ثابت و مرتب، لاگ کاملاً خاموش، کپی کامل outboundهای اعضای دارای تأیید اتصال تازه و لینک‌های کلی/تکی مستقل؛ تعداد اعضا از Setting تنظیم می‌شود.
- Splash: کلید مستقل برای هر لینک در Input؛ اسمارت اسپلش با تعداد اعضای جدا در Setting، کش، صف و لینک کلی/تکی مستقل. اعضای عادی وارد آن نمی‌شوند و کانفیگ متعلق به اسپلش، حتی اگر در منبع عادی تکرار شود، از اسمارت عادی کنار گذاشته می‌شود.
- Setting: نگهداری، دریافت موازی، تایم‌اوت و تنظیمات تبدیل/بررسی خودکار.
- قالب مشترک شامل DNS، SOCKS محلی، مسیریابی، آمار و سیاست نمونهٔ کاربر است. آدرس، احراز هویت، پروتکل و انتقال از خود کانفیگ می‌آیند. وابستگی‌های قابل تشخیص مسیر حفظ می‌شوند.
- اصل داده بدون تغییر و رمزگذاری‌شده باقی می‌ماند. حذف تکراری‌ها، جایگزینی اتمی خروجی هر لینک و عمر ثابت پیش‌فرض دو ساعت حفظ شده‌اند.
- **بانک آزمایش و تعمیر حذف شده است.** نمونهٔ دائمی، تاریخچهٔ نسخه‌ها، مدل‌های یادگیری و ساب‌های قدیمی وجود ندارند. تبدیل فقط تا زمانی باقی می‌ماند که منبع فعلی/زمان نگهداری اجازه دهد.

پروتکل‌های قابل تبدیل: VLESS، VMess، Trojan، Shadowsocks، WireGuard، Hysteria 2/Hy2، SOCKS5 و JSON/Custom JSON قابل تشخیص. Hysteria 1 در هستهٔ هدف پشتیبانی نمی‌شود؛ تبدیل اسم پروتکل آن را سازگار نمی‌کند.

هدف فعلی: **v2rayNG 2.3.15 / Lib40 / Xray 26.10.31**. بایت دقیق هر خروجی با هستهٔ همراه برنامه و **Xray 26.11.9** اعتبارسنجی و روی هستهٔ همراه برنامه اجرا می‌شود. انتشار خروجی ساده، گروهی و Smart به آزمون واقعی HTTPS با گواهی معتبر، DNS و انتقال‌های پشتیبانی‌شده نیاز دارد. نتیجهٔ هسته، اتصال و HTTP/3 جدا ثبت می‌شود.

برای VLESS قدیمی TCP/RAW بدون TLS، درایور واسط محلی با حفظ سرور و UUID و مدیریت پورت و tag اضافه شده است. **این روش رمزنگاری اضافه نمی‌کند.** کانفیگ رمزنگاری‌شده تنزل داده نمی‌شود. موارد پشتیبانی‌نشده یا سرورهای در دسترس‌نبودن با علت مشخص نگه داشته می‌شوند و سالم منتشر نمی‌شوند.

لینک گروهی جدید آرایهٔ JSON و لینک تکی یک شیء JSON است. برای کانفیگ‌های قبلاً دریافت‌شده باید لینک اشتراک جدید را از پنل بردارید و به‌روزرسانی/ایمپورت کنید. آزمون منبع‌محور Import انجام شده؛ اجرای APK روی Android هنوز انجام نشده است. پینگ داخلی برنامه ممکن است کانفیگ واسط محلی را اجرا نکند؛ این با اجرای کامل VPN متفاوت است.

## توسعه

شاخهٔ `go/v2rayng-2.3.6`؛ `main` قدیمی مستقل می‌ماند. Linux، Go و Python 3 لازم‌اند. آزمون رابط به Chrome/Playwright نیاز دارد.

```sh
bash scripts/check.sh
XRAY_TEST_BINARY=/absolute/path/to/pinned/xray go test -v ./internal/convert
PLAYWRIGHT_MODULE=/path/to/playwright-core CHROME_PATH=/path/to/chrome python3 scripts/panel-browser-test.py
sudo -E python3 scripts/client-compat-test.py --integration
sudo -E python3 scripts/conversion-worker-test.py
sudo -E python3 scripts/smart-worker-test.py
sudo -E python3 scripts/smart-worker-test.py --splash
```

پیش‌نیاز worker: هر دو باینری رسمی `/opt/config-repair/core-26.10.31/xray` و `/opt/config-repair/core-26.11.9/xray` با checksum ثبت‌شده در [pins](docs/reports/P33-source-pins.json). نبودن یا عدم تطابق هسته اجازهٔ انتشار نمی‌دهد. آزمون اختیاری HTTP/3 از محیط مستقل aioquic1.3.0 استفاده می‌کند؛ نصب نبودن آن نتیجهٔ `not_run` می‌دهد.

کارگر privileged فقط محیط ایزولهٔ هسته را مدیریت می‌کند؛ کانفیگ‌ها با UID غیرریشه، محدودیت منابع، فایل‌سیستم محدود و کنترل خروجی شبکه اجرا می‌شوند. شش سرویس systemd پس از بوت و خطای فرایند خودکار اجرا می‌شوند؛ هنگام خاموشی خود سرور پردازشی ممکن نیست.

پنل طبق درخواست بدون حساب/رمز است؛ هر شخص دارای دسترسی به آدرس می‌تواند آن را مدیریت کند. کلیدها، لینک‌های محرمانه، داده‌ها و نسخه‌های پشتیبان هرگز وارد Git نمی‌شوند. نصب‌کنندهٔ نهایی خودکار هنوز یک مرحلهٔ انتشار مستقل است.

[راهبرد سنجش و بهبود عملکرد اسمارت](docs/SMART_PERFORMANCE.md)

برای استفاده از اسپلش، دکمهٔ «اسپلش · Splash» کنار منبع را فعال کنید؛ سپس تعداد را در بخش «خروجی اسمارت اسپلش» تنظیم و لینک‌ها را از `/smart-splash` بردارید. منابع موجود هنگام ارتقا عادی باقی می‌مانند. اگر عضو معتبر یا سرور IP مستقل در خود مجموعهٔ اسپلش نباشد، ساخت منتظر می‌ماند؛ از مجموعهٔ عادی عضو اضافه نمی‌شود.
