# V2Ray Config Repair — Go

سامانهٔ تعمیر و سازگارکردن کانفیگ برای **V2RayNG 2.3.6 / Lib v40 / Xray-core v26.7.28**.

این شاخه، نسل مستقل Go پروژه است. شاخهٔ `main` فعلاً کد نسل قبلی را نگه می‌دارد.
هدف نهایی: پنل فارسی مدیریت لینک‌ها، دریافت دائمی و موازی، تعمیر کنترل‌شده، تبدیل به Custom JSON در صورت نیاز، تست و اشتراک قابل‌اعتماد، همراه نصب‌کنندهٔ خودکار سرور.

## وضعیت واقعی این نسخه

این نسخه **پایهٔ توسعه است، نه محصول آمادهٔ استفاده**.

- پروفایل هدف و commit سورس‌های مرجع ثبت شده‌اند.
- قرارداد درایورها، سیاست جایگزینی نسل منابع و بازهٔ تصادفی زمان‌بندی پیاده شده‌اند.
- بررسی اولیهٔ ساختار Custom JSON و تعمیر دقیق `stats: []` به `stats: {}` پیاده شده است.
- تعمیر فقط همان بازهٔ بایت را عوض می‌کند؛ سایر محتوا و فیلدهای ناشناخته حفظ می‌شوند.
- بررسی ساختار، تست هسته، واردکردن در اندروید و اتصال واقعی وضعیت‌های جدا دارند.
- پنل، Fetch دائمی، سایر تعمیرها، تبدیل URI به JSON و خروجی اشتراک هنوز پیاده نشده‌اند.
- تست روی خود برنامهٔ اندروید هنوز انجام نشده؛ موفقیت تست Linux Xray جای آن را نمی‌گیرد.

## مسیر ادامه

از [Project Brain](docs/PROJECT_BRAIN.md)، [وضعیت فعلی](PROJECT_STATE.json) و [تحویل مرحله](HANDOFF.md) شروع کنید.
تقسیم مراحل و معیار پایان هر بخش در [نقشهٔ راه](docs/ROADMAP.md) است.
شواهد نسخهٔ هدف در [گزارش بررسی سورس](docs/compatibility/v2rayng-2.3.6.md) قرار دارد.

## اجرای توسعه

Go 1.24 یا جدیدتر، Linux و Python 3 برای اسکریپت‌های بررسی لازم است.

```sh
bash scripts/check.sh
./bin/config-repair target
./bin/config-repair inspect /path/to/config.json
./bin/config-repair repair-stats /path/to/broken.json /path/to/new-candidate.json
python3 scripts/fetch-core.py
python3 scripts/core-smoke.py --core .local/xray-26.7.28/xray
python3 scripts/android-preflight.py
```

`inspect` فقط مشکلات شناخته‌شدهٔ ساختاری را گزارش می‌کند. مقدار `publishable` همیشه `false` است؛ مسیر انتشار در این مرحله وجود ندارد.
`repair-stats` فایل اصلی را تغییر نمی‌دهد، فایل خروجی موجود را بازنویسی نمی‌کند و یک **کاندید تعمیرشده** می‌سازد.

هیچ لینک خصوصی، کلید، دیتابیس عملیاتی، خروجی خام یا تنظیمات محرمانه‌ای نباید commit شود.
نصب‌کنندهٔ خودکار محصول پس از تکمیل تست‌ها، تست Android و نصب/ارتقا/برگشت منتشر خواهد شد؛ اسکریپت‌های فعلی ابزار توسعه‌اند.
