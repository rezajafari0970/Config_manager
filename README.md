# Config Manager — Go

پنل مستقل مدیریت و دریافت کانفیگ، با سه بخش **Input / Output / Setting** و رابط فارسی مناسب موبایل.
شاخهٔ توسعه `go/v2rayng-2.3.6` است؛ کد قدیمی `main` مستقل باقی می‌ماند.

## قابلیت‌های فعال

- بدون نام کاربری و رمز؛ هر کسی که به آدرس پنل دسترسی داشته باشد می‌تواند آن را مدیریت کند.
- افزودن گروهی لینک‌ها، نام خودکار از پوشهٔ قبل از فایل، ویرایش، حذف، توقف و دریافت فوری هر لینک.
- یک فیلد بازهٔ درخواست مانند `۲ تا ۳` با ثانیه یا دقیقه؛ زمان تصادفی مستقل برای هر لینک.
- دریافت موازی با تایم‌اوت واقعی برحسب ثانیه؛ پیش‌فرض مشترک و مقدار مستقل برای هر لینک. بازیابی پس از توقف فرایند و شروع خودکار پس از روشن‌شدن سرور.
- وضعیت جداگانهٔ فعال/متوقف، قالب خوانا، خروجی خراب، پاسخ خالی و خطای درخواست.
- انتخاب گروهی لینک‌ها و کانفیگ‌ها برای فعال/غیرفعال‌کردن و حذف؛ دکمه‌های حذف همهٔ لینک‌ها و همهٔ کانفیگ‌ها.
- استخراج URI، JSON/Custom، Base64 و WireGuard؛ فایل اصلی پاسخ و محتوای استخراج‌شده بدون بازنویسی نگهداری می‌شوند.
- حذف تکراری‌ها در خروجی مشترک، با مالکیت مستقل هر منبع.
- نگهداری پیش‌فرض دو ساعت از اولین ثبت؛ قابل تنظیم در Setting. دریافت تکراری یا 304 این زمان را تمدید نمی‌کند.
- دانلود هر فایل اصلی و ZIP فایل‌های یکتا؛ محدودیت قبلی تعداد منابع، طول URL، بدنهٔ درخواست و سقف ۳۰ روز حذف شده است.

**Output خروجی خام است و تأیید اتصال VPN نیست.** این مسیر طبق درخواست جدید هیچ تعمیر یا تغییر محتوایی انجام نمی‌دهد. ابزار اولیهٔ تعمیر CLI جداست. سازگاری کامل و تست اندروید V2RayNG 2.3.6 / Lib v40 / Xray 26.7.28 هنوز تکمیل نشده‌اند.

## توسعه و استقرار

Linux، Go 1.26+ (آزموده‌شده 1.27.1)، Python 3 و برای تست رابط Chrome/Playwright لازم‌اند.

```sh
bash scripts/check.sh
PLAYWRIGHT_MODULE=/path/to/playwright-core CHROME_PATH=/path/to/chrome python3 scripts/panel-browser-test.py
./bin/config-panel -config /etc/config-repair/panel.json
```

[راهنمای پنل](docs/PANEL.md)، [معماری](docs/ARCHITECTURE.md)، [وضعیت](PROJECT_STATE.json)، [تحویل](HANDOFF.md) و [نقشهٔ راه](docs/ROADMAP.md) را ببینید.
نمونهٔ systemd و nginx در `deploy/` است. نصب‌کنندهٔ نهایی خودکار هنوز منتشر نشده است.
هیچ URL محرمانه، خروجی خام، کلید یا دیتابیس عملیاتی نباید وارد Git شود.
